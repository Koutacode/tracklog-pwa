# IC名の取得・保存・同期・表示の修正

## 対象と原因

2026-10-06、TrackLog本体のIC名未表示を修正。公開済みAPKを検証した結果、旧正式版はv0.1.69 / versionCode 67。修正版はv0.1.70 / 68。利用者申告の画面バージョンとの差異は添付画像そのものを取得できないため未解決。

- 本番resolver v5には個別10秒・全体28秒・失敗先cooldownがあるがmainに未収録。既存PR #26も読んだうえで、その本番差分を今回の修正へ取り込んだ。
- 日報の地点情報は名前が存在するときだけIC行を表示し、取得状態を無視。保存日報の投影もresolved名だけを扱い、pendingの推定名と失敗状態を更新しなかった。
- 通信失敗はpendingのまま上限なく継続し、起動・復帰・認証更新で待機時間と回数をリセットする経路があった。
- 同期の不完全なextrasや競合は、手動修正・推定根拠の欠落または古い値への復帰を起こし得た。
- 取得経路はOverpassのみ。保存エラーには406、504、timeoutがあり、待ち時間延長だけでは可用性を保証できない。

## 実装

- 共通IC表示を日報・詳細修正・履歴・ホーム・運行履歴出力へ使用。名前なしも「IC名未取得」と状態を表示し、候補・確定・手動修正を区別する。
- 推定候補と根拠を独立したmetadataとして維持。複数候補は全候補を表示。旧APK向け応答にも推定の文字を残す。
- 取得アルゴリズム15。通信・認証失敗を含む自動試行を6回以内に制限。永続待機時間と回数を起動・復帰でリセットしない。バッチ最大20、並列2。記録後の非同期処理を維持する。
- 外部照会は最大3要求・全体28秒以内、半径2.2km以内。406/429とRetry-Afterの冷却、応答本文までの期限、部分成功の拒否を実装。
- 入口/出口表記を保持し、イベント種別と逆の候補・JCT・destinationだけの名前を採用しない。近接地図候補は推定で返し、距離だけで確定しない。
- Overpassの旧kumi別名を現行private.coffeeへ更新。同じ運営を独立した代替先として重複登録しない。
- IC専用の同期mergeとprivate triggerで旧端末の書込みも保護。非ICフィールド、時刻、ODO、位置、区間を変更しない。既存行の一括更新は実施しない。

## 検証範囲

匿名の合成データで名前なしpending、推定名ありpending、複数候補、確定名、手動修正、通信失敗、再試行成功、同期競合、IndexedDB再起動を検証。再取得成功でも推定根拠の履歴を残す。

基本検証はtypecheck、test:logic、test:sync、check:csp、build、check:offline、release検証テスト。Edge FunctionsはDenoの型検査を実施。Androidは単体112試験と本体・androidTest APKコンパイルを実施。

Browser pluginは提供されていないため、Playwrightと既存Chromiumを使用。実コンポーネントTripDetailを合成IndexedDBで表示し、412px / 1280px画面で状態の違いと「詳細→IC名手動編集→保存→再読み込み後保持」を確認。コンソールエラー・Viteエラーなし、操作前後で時刻・ODO・住所・区間が不変。認証は合成fixtureの範囲外。

本番は対象の高速イベント7件に限定して確認し、推定名6件と名前なし1件を分離。GPS履歴の取得は行わず、非公開ID・座標・実運行データをこのリポジトリやテストへ載せていない。

## 配布・本番確認

SupabaseのIC取得関数はv6として反映し、JWT検証を保持。デプロイ後の3ファイルはソースと完全一致を確認。IC保全migrationも本番へ適用し、private / security invokerのtriggerが有効であることを確認した。対象7イベントの運行項目とextrasのfingerprintは反映前後で一致し、既存推定6件も保持。security advisorは適用前と同じ既存INFO14件・WARN1件で、新規指摘なし。

通常のAndroid Release workflowで既存署名のAPKを公開する。PRのHEAD、main、tagのSHAとCIを照合し、公開APKのpackage/version/code/署名/SHAを検証してから正式成果物として扱う。旧リリース資産は保持する。

サーバー反映とAPK更新は別工程。サーバーだけでは旧APKの欠落した状態表示は直らない。運行終了後にlatest APKで上書き更新し、オンラインで同期してIC表示を確認する。アンインストール・データ消去はしない。

実機未接続のため本人端末表示、実走行、GPS、通知、電池最適化、認証付き本番のIC取得成功は未確認。Cloudから外部地図サービスへの実照会は環境の許可ホスト制限で403。本番記録の406/504とは別の制約。国交省N06全国ICデータによる代替経路は公式配布ホストへ接続できず今回未導入。IC名取得の可用性を確認済みとは報告しない。

リリース後のSHA・URL・本番適用結果・公開APK照合・Drive保管結果は既存の非公開月次作業ログに追記する。
