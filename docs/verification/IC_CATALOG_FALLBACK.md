# IC名取得の残存失敗と公開IC候補データ

2026-10-06、v0.1.70の状態表示が端末へ届いた一方、本番のOverpass三接続先が406・504・タイムアウトで失敗し、名前なしのイベントが残ることを確認した。取得経路を追加した版はv0.1.71 / versionCode 69。オンラインで候補上限の拒否を回避する経路も閉じた最終版はv0.1.72 / versionCode 70。

## 取得経路

- 国土数値情報N06-25の公開派生データから、通常IC1,942件・スマートIC164件、計2,106件を同梱。記録済み位置から同期的に検索でき、候補があれば認証・外部通信とも不要。
- 公式ZIPはCloud接続制限で未取得。独立して公開されている固定commitのPMTilesを取得し、N06由来の名前・種別・点だけを抽出した。追加の人口順位や車線情報は転載していない。
- 入力artifactのSHA-256、出典、全z14タイル検査、重複の整合、量子化幅を記録。再生成手順と利用範囲は [公開ICデータのREADME](../../shared/ic-catalog/README.md) に記載。
- 元の開通年は公開派生データに残らないため再検証できない。現在供用、利用入口・出口・進行方向を確認した名前ではなく、すべて推定候補として扱う。
- 1,200m以内の全候補を保持し、12件を超える密集結果は勝手に選ばない。イベント位置に候補がない場合も、既存の時間窓・精度条件・最大3点・元位置から2kmの上界を満たす保存軌跡を、外部照会より先に検索する。
- IC名専用 `resolve-name` と既存道路判定を分離。公開IC点から高速道路内外を判断せず、開始終了・終了確認の既存経路を維持する。候補がない場合だけ既存の有限Overpass経路へ進む。

## 保存と表示

- アルゴリズム16で旧版の失敗を有限の再試行対象へ戻す。オフラインのデータ未該当は通信試行として計上せず、以前のエラーと待機時間を保持。
- 住所由来の既存入口・出口・複数候補を主表示に残し、新しい公的候補を補助候補として併記。双方の根拠と出典日付を保存。手動名・確定名へ過去候補を混在させない。
- 自動IC情報の鮮度ではアルゴリズム版を時計の前後より優先。ICメタデータの時刻だけを単調化し、実イベント時刻・ODO・区間・GPS・積卸・休憩・休息を変更しない。
- 新規の関数のみのDB migrationで旧版からの巻戻りを防止。適用済みmigration、既存行、RPC、権限を変更する一括処理は行わない。

## 検証と本番

- 匿名データで通信停止中の候補取得、位置なし、候補なし、補足軌跡、複数候補、距離上界、旧版失敗、手動修正、同期競合、再起動、時計逆行を検証。
- 取得統合40件（補足点の候補合流が12件を超えた場合の全件拒否と、オンラインの再照会でも拒否を回避しないことを含む）、画面17ケース、同期36チェック。公開データ抽出の匿名11件、候補検索6件、名前専用サーバー5件、既存を含むEdge36件が成功。期限の試験は制御時計と停止した応答本文で検証する。
- 実Chromiumの412px / 320px日報・詳細で長い補助候補の折返し、横はみ出し0px、手動編集から再読込後の保持を確認。合成記録の運行項目・他イベントの根拠は不変、console error / warnなし。
- Edge型検査はDenoによるnode_modulesの書換えを無効化し、`npm ci`で固定したAPK側の依存を検査途中で置換しない。未生成・小さなfixture・不正な公開データはbuild前の検査で拒否する。
- 型検査、ロジック、同期、公開APK検証スクリプト、CSP、Web build、オフライン資産検査、Android同期とビルドが成功。Android単体試験112件は失敗・スキップなし。接続端末の計装試験は実行していない。
- 本番resolver v7を反映し、JWT検証と端末承認を維持。取得し直した6ソースファイルが完全一致。新IC保護関数も本番の本文ハッシュ・invoker・有効triggerを確認。
- 対象の高速イベント7件だけをDB内で照合。6件は保存位置、残る1件は必要な2分間の軌跡13点の集約だけで検証した。座標そのものや生の履歴をCloud・テスト・公開資料へ取得していない。
- 対象7件は名前付き・候補取得済みへIC情報だけを修復。元の推定名6件と住所由来根拠を保持し、時刻・位置・住所・ODO等の非IC項目のfingerprintは前後一致。近接候補を確定名へ変更していない。

通常のAndroid Release workflowで公開し、最終SHAのCIと公開APKの署名・version・SHAを照合する。旧リリースとAPKを保持し、確認済み公開APK・SHA・最終検証記録を既存の非公開Drive月次記録へ保存する。

本人端末での新しいIC名表示、認証付き本番 `resolve-name` の応答、実走行・GPS・通知は未確認。外部Overpassの実通信成功を確認したとは報告しない。APK更新後、オンライン同期して日報を再表示する。更新は運行終了後の上書きとし、データ消去を伴う操作は不要。
